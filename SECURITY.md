# Security Policy

Thank you for helping keep **Yomikoe** secure.

We take security issues seriously and appreciate responsible disclosure from the community. Even though Yomikoe is an open source project, we aim to respond to security reports promptly and transparently.

---

# Supported Versions

Security updates are provided on a best-effort basis.

In general:

| Version               | Supported |
| --------------------- | :-------: |
| Latest main branch    |     ✅    |
| Latest stable release |     ✅    |
| Older releases        |     ❌    |

If you're using an older version, please upgrade to the latest supported release before reporting a security issue.

---

# Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public GitHub issue**.

Instead, report it through one of the following channels:

* GitHub Security Advisories (preferred)
* A dedicated security email address (when available)

Please include as much information as possible, such as:

* A description of the vulnerability
* Steps to reproduce the issue
* The affected version or commit
* Potential impact
* Proof of concept, if appropriate

Providing clear reproduction steps helps us investigate and resolve issues more efficiently.

---

# Disclosure Process

We follow a responsible disclosure process.

1. Report the vulnerability privately.
2. We acknowledge receipt of the report.
3. We investigate and validate the issue.
4. A fix is developed and released.
5. Once users have had an opportunity to update, the vulnerability may be disclosed publicly.

Please avoid publicly discussing undisclosed vulnerabilities until a fix has been released.

---

# Response Expectations

While Yomikoe is maintained by volunteers, we will make a best effort to:

* Acknowledge valid reports as soon as practical.
* Keep reporters informed about the investigation.
* Prioritize vulnerabilities based on their severity and impact.
* Release fixes as quickly as reasonably possible.
* Credit reporters for responsible disclosure, if they wish to be acknowledged.

Response times may vary depending on maintainer availability and the complexity of the issue.

---

# Thank You

We appreciate everyone who helps improve the security of Yomikoe through responsible disclosure and constructive collaboration.
