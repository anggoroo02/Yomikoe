# Core Architecture

## Purpose

This section defines the internal software architecture of Yomikoe.

It explains how the system is organized into modules and how those modules communicate.

---

## Scope

The documents in this directory answer questions such as:

- How is the application structured?
- What modules exist?
- What interfaces connect modules?
- How can the system be extended?
- How are dependencies managed?
