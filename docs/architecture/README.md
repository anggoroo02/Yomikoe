# Architecture

This directory contains the architectural documentation of Yomikoe.

The architecture documentation is organized into four layers.

## Structure

### 01 Foundation

Defines the project's vision, requirements, repository organization, and architectural principles.

### 02 Domain

Describes the business domain, processing model, and core concepts.

### 03 Core

Defines the internal software architecture, modules, contracts, and extension mechanisms.

### 04 Governance

Reserved for long-term architectural governance documents.

## Recommended Reading Order

1. Foundation
2. Domain
3. Core
4. Governance

## Relationship with Other Documentation

Architecture documents define the system.

Engineering tasks implement the architecture.

Development documents describe engineering processes.

ADR documents record architectural decisions.

Reference documents provide supporting material.

## Notes

Architecture documentation is the single source of truth for software design.

Implementation must conform to these documents.
